# फील्ड नकाशा (FieldMap) Android app

फोनचे GPS लोकेशन घेऊन ठिकाणांची यादी बनवते. यादी KML आणि CSV फाईल म्हणून शेअर करता येते. ती फाईल Google My Maps मध्ये Import केल्यावर नकाशा तयार होतो.

## APK कसा मिळवायचा (Android Studio शिवाय)

1. github.com वर नवीन repository तयार करा.
2. या फोल्डरमधील सर्व फाईल्स (`.github` फोल्डरसह) त्या repository मध्ये upload करा.
3. Repository मधील **Actions** टॅब उघडा. **Build APK** चालू होईल. 3 ते 5 मिनिटे लागतात.
4. पूर्ण झाल्यावर त्या run मध्ये **Artifacts** खाली **FieldMap-apk** डाउनलोड करा. zip उघडल्यावर `app-debug.apk` मिळते.
5. फोनमध्ये APK उघडून Install करा. "अज्ञात स्रोत" (Unknown sources) परवानगी विचारल्यास द्या.

## Android Studio मध्ये

Android Studio मध्ये हा फोल्डर Open करा, Gradle Sync होऊ द्या, फोन USB ने जोडून Run दाबा.

## वापर

1. ठिकाणाचे नाव लिहा, प्रकार निवडा.
2. **माझे लोकेशन घ्या** दाबा. मोकळ्या जागेत अचूकता ±20 मी पर्यंत येते.
3. **यादीत जोडा** दाबा.
4. सर्व ठिकाणे जोडल्यावर **CSV + KML फाईल शेअर करा** दाबा आणि Drive, WhatsApp किंवा Gmail निवडा.
5. My Maps मध्ये (संगणकावर सोपे) नवीन नकाशा तयार करा, **Import** दाबून KML फाईल निवडा.
